# ZakoWhat — Project Instructions

## Project
ZakoWhat is an Uzbek-language intellectual quiz platform.

## Stack
- FastAPI / Python
- SQLAlchemy
- PostgreSQL / Neon
- Jinja2
- Vanilla JavaScript
- Railway (planned hosting)

## Core Features
- Zakovat (2×12)
- Svoya Igra (Free Choice and Classic)
- Daily Question (Kun savoli)
- Arena quiz catalog
- Player profiles and statistics
- Authentication and owner panel

## Development Rules
1. Inspect existing implementation before modifying it.
2. Preserve existing uncommitted changes.
3. Avoid unrelated refactoring.
4. Reuse existing architecture and functions.
5. Add focused regression tests for bug fixes.
6. Run relevant tests after modifications.
7. Run the full suite after completing a coherent feature.
8. Distinguish verified facts from assumptions.

## Critical Restrictions
- Never deploy without explicit permission.
- Never commit or push without explicit permission.
- Never modify production databases without explicit permission.
- Never delete or discard existing work without explicit permission.
- Never overwrite unrelated changes.

## Workflow
For every task:
1. Understand the relevant code.
2. Identify the root cause or implementation plan.
3. Make the smallest appropriate change.
4. Verify the result.
5. Report files changed and test results.

Keep reports concise. Avoid repeated full-project audits.
